
# Project & Task Tracking Dashboard

## Project Overview
The Project & Task Tracking Dashboard is created using Power BI to monitor project progress, task status, employee performance, and completion percentages. It helps track projects and tasks efficiently and ensures timely completion.

## Objectives
- Track total, completed, in-progress, and pending projects.
- Monitor task status and completion percentage.
- Analyze employee-wise performance.
- Identify overdue tasks and upcoming deadlines.
- Improve project planning and productivity.

## Tools & Technologies
- Power BI
- Microsoft Excel
- DAX

## Key Features
- **Project Overview:** Displays total projects and their current status.
- **Task Tracking:** Monitors task progress and completion.
- **Employee Performance:** Compares employee-wise task completion.
- **Overdue Tasks:** Helps identify tasks that have passed their due dates.
- **Interactive Filters:** Uses slicers to filter and analyze project information.

## Key Performance Indicators (KPIs)
- Total Projects
- Completed Projects
- In-Progress Projects
- Pending Projects
- Average Completion Percentage
- Task Completion Status

## Conclusion
This dashboard provides a clear overview of project and task progress. It helps monitor employee performance, identify delays, and support better decision-making to complete projects on time.
